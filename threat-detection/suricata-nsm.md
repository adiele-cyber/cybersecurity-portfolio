# Suricata Network Security Monitoring

## Objective
Use Suricata to monitor network traffic and identify suspicious
or malicious activity.

## Environment
- Suricata running on Linux
- Traffic mirrored from internal network

## Steps
1. Installed Suricata
2. Configured network interface for live traffic capture
3. Enabled Emerging Threats rule set
4. Generated test traffic to simulate attacks
5. Reviewed Suricata event logs

## Observations
Suricata detected port scanning and suspicious HTTP requests.

## Outcome
Network-based threats were successfully identified and logged
for further investigation.
