# Snort Intrusion Detection System

## Objective
Deploy Snort to detect suspicious network activity and generate
alerts for potential attacks.

## Environment
- Linux system running Snort
- Simulated client and attacker machines

## Steps
1. Installed Snort and required dependencies
2. Configured network interface for traffic monitoring
3. Enabled default detection rules
4. Started Snort in IDS mode
5. Generated test traffic to trigger alerts

## Detection Example
Multiple TCP connection attempts to restricted ports were detected
and logged by Snort.

## Outcome
Snort successfully generated alerts for abnormal network behavior,
providing visibility into potential attacks.
