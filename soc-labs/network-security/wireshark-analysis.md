# Wireshark Network Traffic Analysis

## Objective
Analyze network traffic to validate alerts and investigate
suspicious behavior.

## Environment
- Wireshark installed on monitoring system
- Traffic captured during simulated attack scenarios

## Steps
1. Started packet capture on active network interface
2. Filtered traffic by IP address and protocol
3. Identified repeated connection attempts
4. Reviewed packet details to confirm abnormal behavior

## Findings
Repeated connection attempts and unusual packet patterns
were observed, supporting IDS alerts.

## Conclusion
Wireshark provided packet-level visibility that confirmed
the presence of suspicious network activity.
