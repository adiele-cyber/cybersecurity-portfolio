# Sophos Firewall Deployment

## Objective
Deploy and configure Sophos Firewall to control network traffic
and enhance perimeter security within a lab environment.

## Environment
- Sophos Firewall (Virtual Appliance)
- Internal network segment
- Simulated client and server systems

## Configuration Summary
Firewall rules were created to allow legitimate traffic,
restrict unauthorized access, and log security-relevant events.

## Monitoring & Logging
Traffic logs and security events were monitored to validate
rule effectiveness and identify blocked connection attempts.

## Outcome
A functional firewall deployment providing visibility and
control over network traffic.
