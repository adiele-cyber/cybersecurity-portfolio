# Wazuh SIEM Deployment

## Objective
Deploy and configure Wazuh SIEM to collect, analyze, and alert on
security-relevant system events.

## Environment
- Operating System: Ubuntu Server (AWS EC2 Instance)
- SIEM: Wazuh
- Purpose: Centralized log collection and security monitoring

## Deployment Summary
Wazuh was successfully installed and configured to ingest system
and authentication logs. Agents were enrolled, and baseline alerts
were verified to ensure visibility into security events.

## Challenges & Resolutions
During deployment, resource constraints affected performance.
This was resolved by adjusting EC2 resources and optimizing services.

## Outcome
A functional SIEM environment capable of monitoring host activity
and generating actionable security alerts.
